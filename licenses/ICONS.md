# Icon and font sources

## Icons
Platform and technology marks come from **Simple Icons** (https://simpleicons.org), icon data
released under CC0 1.0.

- Simple Icons 16.36.0: every mark except LinkedIn.
- Simple Icons 13.0.0: the LinkedIn mark only. Current releases no longer include it, so it was
  taken from this last release that did. Source: the `simple-icons` package on npm, version 13.0.0.

Brand names and logos remain trademarks of their owners and are used here only to point to the
owner's own profile or technology.

## Fonts
Embedded as subsetted WOFF2 (only the glyphs used). All three are SIL Open Font License 1.1:
Syne (Syne-OFL.txt), Manrope (Manrope-OFL.txt), DM Mono (DM-Mono-OFL.txt).
